# 筑波大学大学院 授業推薦システム
成績データとシラバス情報をもとに、筑波大学大学院の学生に対して専攻横断の授業を推薦するWebアプリケーションです。  
学生が「どの授業があるかわからない」「自分に合う授業がわからない」「時間割を作るのが大変」という課題を抱えていたため、授業内容の自然言語処理と数理最適化を組み合わせて、履修候補の推薦と時間割作成を支援するシステムを開発しました。

アプリケーション: https://topic-based-recommender.streamlit.app/

---

## 1. 課題設定

筑波大学大学院システム情報工学研究群では、自身の学位プログラムだけでなく、他の学位プログラムの授業も履修する必要があります。  
一方で、社会工学、サービス工学、リスク・レジリエンス工学、情報理工、知能機能システム、構造エネルギー工学など複数の学位プログラムに授業が分散しており、学生が自力で自分に合う授業を探す負担は大きいです。  
そこで本プロジェクトでは、学生の成績データと授業シラバスを用いて、関心分野に近い大学院授業を推薦し、時間割制約を考慮して履修候補を提示することを目的としました。

---

## 2. 使用データ

主に使用したデータは、大学院授業のシラバス情報と、学生の履修済み授業・成績データです。  
シラバスは「授業内容を表す文書」として扱い、KeyBERTによって各授業のキーワードを抽出しました。  
成績データは、学生が過去に履修した授業に対する興味・適性を表す情報として利用し、履修済み授業のトピック分布を成績で加重平均することで、ユーザーごとの関心トピックを算出しました。  
前処理では、シラバステキストから授業内容に関係する語を抽出し、後続のトピック分類と推薦スコア計算に利用できる形へ変換しています。

---

## 3. アプローチ

推薦手法として、協調フィルタリングとコンテンツベースフィルタリングを比較しました。  
協調フィルタリングは他ユーザーの履修履歴を活用できる一方、今回は十分な人数分の成績データを確保できなかったため採用しませんでした。  
代わりに、シラバスという授業内容のテキストデータを活用できるコンテンツベースフィルタリングを採用しました。  
自然言語処理にはLDA（Latent Dirichlet Allocation）を用い、授業を「社会設計・コミュニケーション」「人間と認知の工学」「情報工学」「社会の数理モデル」「都市・土木」「経済・金融・政治」の6トピックに分類しました。

処理フローは以下の通りです。

1. KeyBERTで各授業のシラバスからキーワードを抽出
2. LDAで各授業のトピック分布を推定
3. 学生の履修済み授業と成績から、ユーザーの関心トピックを算出
4. 授業トピックとユーザー関心度を掛け合わせて推薦スコアを計算
5. 数理最適化により、時間割の重複を避けながら履修候補を出力

---

## 4. 改善内容

初期版を実装・デプロイした後、ユーザーから「推薦精度が低い」という指摘を受けました。  
原因を分析した結果、LDAが単語の完全一致に依存するため、「シミュレーター」と「シミュレーション」、「数学」と「数理」、「郊外」と「都市」のような意味的に近い語を別物として扱ってしまうことが問題だと分かりました。  
この課題に対して、Word2vecを導入し、抽出されたキーワードに意味的に近い語を補完する仕組みを追加しました。  
これにより、授業内容をより広い語彙で表現できるようになり、LDAによるトピック分類の安定性を改善しました。

---

## 5. 結果

Word2vecによるキーワード補完の導入により、授業あたりの平均キーワード数は5.3個から15.5個へ増加しました。  
また、同一トピック内の授業間におけるキーワード重複数の総和は5倍以上に増加し、関連授業同士が同じトピックに分類されやすくなりました。  
テストケースでは、都市計画専攻の学生には都市・住宅系の授業が、社会経済システム専攻の学生には金融・経済系の授業が推薦されることを確認しました。  
最終的に、Streamlitを用いてWebアプリとしてデプロイし、実際に操作できる推薦システムとして完成させました。

---

## 6. 考察

本プロジェクトでは、少人数の成績データしか使えない条件下でも、シラバスというテキストデータを活用することでパーソナライズ推薦を実現できました。  
特に、ユーザーからのフィードバックを起点に精度低下の原因を分析し、Word2vecによる意味的類似度を取り入れて改善できた点が大きな成果です。  
一方で、推薦精度の評価はテストケースによる確認が中心であり、実ユーザーを対象にした定量評価までは十分に行えていません。  
今後は、推薦結果に対する満足度アンケートやクリック率・履修率などの指標を用いて、より客観的に性能を評価する必要があります。

## 7. 今後改善したい点

- ユーザーが興味のある分野を手動で重み付けできる機能を追加する
- 他学類・他研究群の授業にも対応し、推薦対象を拡大する
- 実ユーザーの評価データを収集し、推薦精度を定量的に検証する
- 推薦理由をより分かりやすく表示し、納得感のあるUIに改善する
- 時間割作成だけでなく、履修計画全体を支援できる機能を追加する

## 9. 実行方法

### オンラインで利用する場合

以下のリンクからWebアプリを起動できます。

https://topic-based-recommender.streamlit.app/

### ローカル環境で実行する場合

リポジトリをクローンします。

```bash
git clone <リポジトリのURL>
cd <リポジトリ名>
```

Python 3.11の仮想環境を作成し、必要なライブラリをインストールします。

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Streamlitアプリを起動します。

```bash
streamlit run recommend_graduate_classes.py
```
